# Новостная лента

## Источник

Новости загружаются из RSS-ленты Интерфакса:

- URL: [https://www.interfax.ru/rss](https://www.interfax.ru/rss)
- Формат: RSS 2.0 (XML)
- Для локальной или тестовой подмены URL можно задать переменную окружения `RSS_FEED_URL`; если она не задана, используется URL выше.

## Фильтрация

В новостную выдачу включаются только записи с категориями:

- «Экономика»
- «Бизнес»

Новости других категорий не включаются.

## Данные новости

Для ответа API используются поля RSS:

- `title` — заголовок;
- `link` — ссылка на публикацию;
- `description` — описание, если оно есть;
- `pubDate` — дата публикации, если она есть и корректно разобрана.

## Обработка ошибок и выдача

Записи без заголовка или категории, с отсутствующей/некорректной ссылкой либо с некорректной непустой датой публикации пропускаются с предупреждением в лог. Отсутствующие `description` и `pubDate` допустимы. Ошибка загрузки источника возвращается как `503`, ошибка разбора XML — как `502`.

Endpoint `GET /api/v1/news` принимает `limit` (по умолчанию 50, от 1 до 100) и `offset` (по умолчанию 0, неотрицательное целое). Сначала выдаются записи с более поздним `pubDate`; записи без даты идут после них, сохраняя исходный порядок ленты. При одинаковой дате сохраняется порядок источника. Полное описание контракта находится в [OpenAPI](./openapi.yaml).
