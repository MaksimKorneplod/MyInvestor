# Позиции и торговые операции

Миграция `000004_portfolio` добавляет хранение открытых позиций и истории виртуальных покупок и продаж.
Для связи с учеником требуется схема аккаунтов из миграции `000002_school_accounts`.

- Инструмент идентифицируется кодом ISIN, который каталог MOEX возвращает в поле `id`. Перед первой сделкой сервис торговли должен добавить подтверждённый каталогом ISIN в `trading_instrument` в той же транзакции. При повторном использовании ISIN подходит `INSERT … ON CONFLICT DO NOTHING`.
- Для пары «ученик и инструмент» существует не более одной открытой позиции. Количество хранится в целых штуках. При продаже всего остатка сервис удаляет строку позиции в транзакции продажи. История операций сохраняется.
- Цена сделки и средняя цена покупки указаны за одну акцию в рублях и хранятся как `NUMERIC(24, 8)`. Баланс профиля по-прежнему хранится в копейках. При расчётах сервис торговли должен явно переводить суммы между этими единицами без двоичного `float`.
- История содержит направление (`buy` или `sell`), количество, цену и время сделки. Для стабильного порядка от новых операций к старым используется `ORDER BY executed_at DESC, trade_id DESC`.
